# VOID SIGNAL · 虚空信号

## 安装

Node.js 22.12 或更新版本。

```sh
npm ci
```

## 本地启动

```sh
npm run dev
```

打开终端显示的本地地址。

## Docker 启动

```sh
docker compose up --build
```

打开 http://localhost:8084 。可通过 PORT 环境变量修改端口。

## 行动档案库

完成一局后自动保存逐波有效伤害与击杀。打开页首「行动档案」可：

- 把任意一局设为下一次行动的**比较基准**；基准在部署（开始行动）时锁定。
- 导入 / 导出 `void-signal-archive.json`。导入按稳定行动编号合并：重复条目跳过，同编号不同数据保留本地原值并提示。
- 战斗中导入档案不会替换本局已锁定的基准；损坏文件整批拒绝，档案与基准都保持不变。
- 旧档案（无逐波数据）只在行动结束时比较最终汇总；本地空间不足时可下载待保存内容，稍后再导入。
